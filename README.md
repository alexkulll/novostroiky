# АТЛАС — подбор новостроек

Веб-приложение для подбора новостроек в Москве, Сочи и Екатеринбурге.

Введите город, бюджет и площадь — приложение покажет до трёх ЖК с примерной стоимостью квартиры. В базе — 15 комплексов с источниками, фотографиями и координатами.

## Возможности

- Подбор ЖК по городу, бюджету и площади с сортировкой по примерной стоимости.
- Каталог всех объектов и карта с кликабельными метками.
- AI-ассистент на локальной модели Qwen: понимает запросы, уточняет параметры и показывает карточки ЖК.
- Ипотечный калькулятор с ручным вводом условий банка.
- Исследование с ценами и графиками: [`docs/issledovanie.xlsx`](docs/issledovanie.xlsx).

## Быстрый запуск на Windows

Нужны **Windows x64**, [Python 3.11 или новее](https://www.python.org/downloads/windows/), Git и интернет для установки. При установке Python включите добавление в PATH.

На странице репозитория нажмите **Code → Download ZIP**, распакуйте архив и откройте PowerShell в получившейся папке. Либо клонируйте репозиторий через Git. Выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Приложение откроется в браузере. Подбор, карточки и калькулятор работают без модели; для загрузки карты необходимо интернет-соединение.

## Подключение AI-ассистента

Для ассистента используется **Qwen3-4B-Instruct-2507 Q4_K_M** и **llama.cpp b11612 для Windows/Vulkan**. Нужны Vulkan-совместимая видеокарта и свободное место: модель занимает около 2,5 ГБ, дополнительно загружается архив движка.

После установки зависимостей выполните один раз:

```powershell
.\.venv\Scripts\python.exe setup_ai.py
```

Скрипт скачает [модель](https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF) и [движок](https://github.com/ggml-org/llama.cpp/releases/tag/b11612), проверит их SHA-256 и разместит в папках `models/` и `runtime/`. Эти файлы не входят в репозиторий.

Запустите приложение обычной командой из раздела выше. При первом вопросе ассистент автоматически запустит модель локально на `127.0.0.1:8080`; первый ответ может занять некоторое время. По умолчанию в GPU выгружаются 24 слоя, контекст — 4096 токенов. После остановки сайта сервер модели может оставаться запущенным для следующего запуска.

Если модель не запускается, проверьте Vulkan-драйвер видеокарты и файл `runtime/llama-server.log`. Если порт 8080 занят другим приложением, освободите его и повторите попытку. Без модели остальные функции сайта доступны.

## Как работает расчёт

**Подбор:** цена от за м² × желаемая площадь. Python сравнивает полученный ориентир с бюджетом и сортирует подходящие значения по возрастанию. Это не подтверждает, что квартира заданной площади доступна по такой цене: стоимость и наличие нужно уточнить у продавца. Диапазон ввода площади 10–1000 м² — ограничение интерфейса, а не данные о фактических площадях.

**Ассистент:** модель распознаёт запрос и добавляет разговорное пояснение. Числа, факты из таблицы и расчёты подготавливает Python. Пояснения модели могут содержать неточности и требуют проверки. Реальных отзывов в базе нет; если показан пример мнения, он помечен как вымышленный.

**Ипотека:** аннуитетный платёж рассчитывается по введённым пользователем ставке, сроку и взносу. Расчёт не включает страховки и комиссии и не проверяет право на льготы.

## Структура

```text
app.py                 Интерфейс Streamlit и карта
property_cards.py      Общие карточки ЖК
selection.py           Чтение данных и логика подбора
assistant_service.py   Обработка запросов и работа с моделью
assistant_prompts.py   Системные промпты
launch_ai.py           Запуск локального сервера модели
setup_ai.py            Загрузка модели и движка
mortgage.py            Расчёт ипотеки
data/complexes.csv     Данные, цены и координаты ЖК
images/                Фотографии объектов
docs/                  Таблица исследования
```

Источники цен указаны в карточках и таблице. Данные — исследовательский срез, а не актуальная витрина предложений; цены и сроки могут измениться.
